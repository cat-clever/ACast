# ACast v0.1.5 发布说明

## 核心修复：彻底解决 macOS 双击应用图标没有任何反应的问题

本版本针对 macOS 客户端双击运行进行了系统级调优，彻底消除双击图标无动静、不弹窗口的问题：

### 1. 深度根因与机制修复
* **根因剖析**：桌面端控制程序为 C++ 交互式服务（实时打印 USB 连接、局域网设备与反控指令）。通过 macOS 访达（Finder）双击 `.app` 打开时，macOS LaunchServices 默认不会为命令行服务分配控制台，导致程序在后台静默运行或直接退出，用户视觉上表现为“没有任何反应”；
* **双击自动唤醒终端交互窗口**：
  * 应用入口新增启动环境探测逻辑：当检测到是由 Finder 双击打开（未关联任何终端）时，通过底层 AppleScript 瞬间激活并拉起 macOS 原生 **Terminal（终端）** 弹出独立交互窗口；
  * 窗口内实时完整展示彩色 Banner、多芯片架构（Apple Silicon / Intel）、USB 设备检测、大屏搜索及反向操控交互；
* **全面修复可执行文件权限**：
  * 打包流程中加入 `chmod -R 755` 与可执行文件 `+x` 权限校验，确保解压与拖拽到 `/Applications` 后的正常调用。
