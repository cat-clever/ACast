# ACast v0.2.9 发版说明

## 更新亮点

### 彻底根除 macOS 启动崩溃 (SIGSEGV / EXC_BAD_ACCESS) 与 UI 体验优化
* **彻底根除启动野指针崩溃**：
  * **崩溃根因排查**：macOS Cocoa 客户端在启动初始化时，`SetUsbDeviceCallback` 和 `SetDiscoveredPhonesCallback` 接收由核心回调传递的局部 `std::vector` 临时对象；当通过 GCD `dispatch_async` 抛给主线程更新设备下拉菜单时，异步闭包引用了外部早已销毁的局部栈内存，导致主线程执行时发生非法内存访问（`KERN_INVALID_ADDRESS at 0x0000000176f5ef30`）；
  * **安全生命周期保护与深拷贝重构**：
    * 采用 `std::make_shared` 将设备数据安全托管至堆内存，使智能指针生命周期安全贯穿至主线程 GCD 调度完成；
    * 增加 `SafeStr` 字符串安全防爆转换，杜绝因特殊设备字符或空值向 NSDictionary 插入 `nil` 引起的异常闪退；
* **界面文字优化**：
  * 将控制端更新按钮文字由“原地热更新”直接精简优化为“**更新**”，界面文案更加简洁大方、符合主流系统交互习惯。
