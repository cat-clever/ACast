# ACast v0.3.7 发版说明

ACast v0.3.7 专项解决了“点击弹出独立控制屏幕窗口后，主窗口的屏幕控制没有关闭”的问题，实现了主控制视窗与独立专属控制视窗的独占式互斥联动与自适应收回机制。

---

## 核心技术与体验优化亮点

### 1. 弹出独立控制屏幕后，主窗口屏幕控制自动关闭（Exclusive Detached Control）
* **主窗口控制视图与导航条智能关闭**：
  当用户点击【⤢ 弹出独立控制屏幕窗口】或手机直连自动弹出独立窗口时，主窗口左侧原有的手机画面投屏视窗（`screenView`）和底部的金刚三大导航键（`screenNavBar`）自动关闭隐藏，彻底杜绝主窗口与独立视窗重复显示和画面重复解码的问题。
* **优雅的独立运行待命占位面板（Detached Placeholder Panel）**：
  主窗口左侧原屏幕控制区域自动切换为深色优雅的待命占位卡片，清晰呈现手机投屏状态，并提供居中的【⤓ 收回控制屏幕至主窗口】按钮。
* **智能双向双控收回联动（Two-way Seamless Re-attach）**：
  - 顶部按钮动态联动为【⤓ 收回控制屏幕至主窗口】；
  - 无论用户是在主窗口点击收回按钮，还是直接在独立控制视窗左上角点击关闭（红叉），独立窗口平滑退出，主窗口的屏幕控制与导航按键均自动、无缝重新开启；
  - Windows 端与 macOS 端同步实现弹出与收回的按钮状态与视窗互斥联动。
* **降低系统开销与视频硬解功耗**：
  当独立控制视窗打开时，底层视频回调只定向解码分发至独立视窗的渲染器，停止主窗口的冗余绘制，大幅节省 CPU 和 GPU 资源。
