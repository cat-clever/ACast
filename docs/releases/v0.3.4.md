# ACast v0.3.4 发版说明

ACast v0.3.4 专项解决了控制端鼠标无法操控手机，以及手机锁屏后导致投屏断开连接的核心问题，带来了更加稳定、低延迟的远程投屏与交互反控体验。

---

## 🌟 核心升级与修复

### 1. 彻底恢复电脑端对手机的鼠标与按键反控 (Mouse & Touch Control)
* **主线程调度与手势容错 (Path Length Fix)**：
  * 排查发现 Android 系统手势框架对 `Path` 长度有严格校验（若起点终点相同且长度为 0，系统会直接判定为 Empty Path 并抛出异常或静默丢弃），导致用户鼠标单击在 Android 14/15/16 (如小米 HyperOS) 上全部失效；
  * 在 `ControlAccessibilityService` 中增加点按微位移容错 (+1.0f)，确保 Path 长度合法；
  * 将所有 `dispatchGesture` 及按键模拟强制调度至主线程 (Main Looper)，杜绝子线程工作队列导致的注入失败。
* **物理像素高精度映射 (RealMetrics)**：
  * 获取屏幕真实物理分辨率（RealMetrics），精准适配打孔屏、全面屏导航栏与状态栏，消除点击位置偏移。
* **手机端无障碍服务一键引导**：
  * 在手机端首页显式添加【🖱️ 电脑鼠标反控】状态卡片：
    * 未开启时显示警示橙色并支持一键跳转系统设置授权；
    * 开启后即时变为绿色状态提示；
  * 清晰指引用户快速开启权限，彻底解决用户不知道需要授权无障碍反控的问题。

---

### 2. 根治手机自动锁屏与连接断开问题 (Keep Screen On & Persistent Link)
* **系统级屏幕常亮保护 (Accessibility Overlay)**：
  * 利用无障碍服务特权（无需额外申请悬浮窗权限），在投屏期间挂载 1x1 像素全局不可见 Overlay 图层并附加 `FLAG_KEEP_SCREEN_ON`；
  * 手机无论处于主界面还是切换到其他 App 玩游戏/看视频，投屏期间均强制保持屏幕常亮，杜绝因闲置自动超时锁屏休眠。
* **CPU 保活 WakeLock**：
  * 在 `ScreenCaptureService` 中申请 `PowerManager.PARTIAL_WAKE_LOCK`，确保后台音视频编解码与 TCP 传输不被系统低功耗休眠中断。
* **网络服务长驻，解耦生命周期**：
  * 彻底移除 `ScreenCaptureService.onDestroy` 中对 `FastMirrorSender` 与 `LocalHttpTsServer` 的暴力关闭调用；
  * 即使用户手动按下电源键熄屏，底层网络端口依然保持监听，控制端不会收到 Connection Reset 报错。
* **熄屏鼠标操作自动唤醒**：
  * 若用户在熄屏状态下在电脑端点击鼠标，手机端自动获取唤醒锁点亮屏幕并恢复交互。
