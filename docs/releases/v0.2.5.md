# ACast v0.2.5 发版说明

## 更新亮点

### 桌面控制端界面架构全面精简与职责纯粹化 (精简方案 1)
* **移除冗余的局域网大屏设备展示卡片**：
  * **职责对齐**：厘清【发射端】与【控制端】的定位边界——向局域网智能电视投屏属于手机发射端的职责，桌面控制端的核心使命是专注于**连接与反控手机**（FastMirror 局域网 Wi-Fi 直连与 USB 专线）；
  * **彻底剔除无交互列表**：彻底移除 macOS 原生 Cocoa 视窗与 Windows 原生 Win32 视窗中的“📺 局域网大屏设备 (DLNA / Cast / AirPlay)”表格与控件，停止无谓的后台大屏组播扫描；
* **日志视窗可视空间倍增**：
  * 移除大屏表格后节省的大块垂直空间全量让给底部的【📋 运行状态与事件日志】；
  * macOS 与 Windows 端终端日志高度扩充近一倍，手机反控链路与系统状态一览无余，视觉体验更加专业与沉浸。
