# ACast v0.2.0 发布说明

## 重大升级：桌面控制端全面升级为纯原生图形界面 (GUI) & 彻底解决 macOS 正则崩溃

本版本针对用户反馈的 **macOS 启动崩溃 SIGABRT** 以及 **桌面控制端依赖终端命令行窗口** 的体验痛点，进行了彻底的原生视窗重构与健壮性升级：

---

### 1. 深度根因分析与技术落地

#### ① 彻底修复 macOS 启动时 SIGABRT 崩溃 (`std::__throw_regex_error<11>`)
* **根因剖析**：
  * 在 macOS 崩溃报告中明确指示：`Thread 2 Crashed: std::__throw_regex_error<(std::__1::regex_constants::error_type)11>()` 触发 `abort()`；
  * 根因位于 `core/src/dlna_controller.cpp` 中的 `std::regex loc_regex("(?i)LOCATION:\\s*([^\\r\\n]+)");`；
  * C++11 标准库 `std::regex`（ECMAScript 规范）并不支持 Perl 风格的 `(?i)` 内嵌前缀标志，Clang 的 `libc++` 在词法解析器遇到 `(?` 时直接抛出 `regex_error(11)` 异常。由于该异步发现线程未全面拦截，导致异常逃逸至顶层调用 `std::terminate()` 造成 SIGABRT 崩溃。
* **修复方案**：
  * 将正则修饰符严格规范为标准 C++ 语法：`std::regex loc_regex("LOCATION:\\s*([^\\r\\n]+)", std::regex_constants::icase);`；
  * 对所有 SSDP 解析、XML 提取及网络握手流程引入全方位的 `try-catch` 异常保护网，确保任何畸形数据包均不会导致进程闪退。

#### ② 桌面控制端全面进化为纯原生 GUI 图形视窗（彻底告别终端命令行窗口）
* **痛点根除**：
  * 过去桌面端依赖控制台（Terminal / Console），在 macOS 下需借助 AppleScript 激活 Terminal.app，容易受到系统权限拦截或弹窗干扰；
* **macOS 原生 Cocoa (AppKit) 视窗**：
  * 采用纯 Objective-C++ 结合现代 Cocoa AppKit 框架编写，由 GPU (Metal/CoreAnimation) 硬件加速渲染合成；
  * 彻底移除所有终端、osascript 唤醒逻辑，双击应用即刻呈现优雅的原生视窗界面；
  * 原生深色/浅色自适应风格，内置精致布局与高清 Retina 适配。
* **Windows 原生 Win32 视窗 (无控制台黑框)**：
  * 采用 Windows 原生 Win32 API 与 Common Controls v6 现代视觉样式构建，编译子系统严格设置为 `/SUBSYSTEM:WINDOWS`；
  * 毫秒级瞬间秒开，零外部庞大第三方运行库依赖，启动时绝不弹黑框控制台。
* **全功能 GUI 界面卡片设计**：
  1. **顶部状态与版本中心**：展示当前系统 IP、客户端版本号（v0.2.0）、一键“检查更新”按钮；检测到新版本时展示高亮更新横幅与“原地热更新”进度条；
  2. **USB 手机反控卡片**：实时展示连接的 Android 手机型号与序列号，自动建立高速反控隧道，提供【返回 (Back)】与【桌面 (Home)】原生按键映射；
  3. **局域网大屏设备视窗**：支持一键重新扫描局域网大屏电视，列表实时展示设备友好名称、IP 地址与控制端点；
  4. **沉浸式实时日志控制台**：在 GUI 视窗内嵌带时间戳的高性能多行等宽字体滚动日志面板，所有后台网络与投屏事件一览无余，支持一键清空。
