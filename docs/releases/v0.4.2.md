# ACast v0.4.2 发版说明

ACast v0.4.2 正式上线 **“在 Mac 上使用 Android 手机摄像头”** 核心功能！安装或接入相机扩展后，用户可在 Zoom、FaceTime、腾讯会议、Photo Booth、Google Meet、Safari 等 macOS 应用中直接选用 Android 高清摄像头。

---

## 核心技术与功能亮点

### 1. 现代 macOS CoreMediaIO 相机扩展系统 (CMIOExtension Architecture)
* **深度遵循 Apple Modern CMIOExtension 架构规范**：
  基于 macOS 12.3+ 新一代 `CoreMediaIO` 系统扩展体系 (`CMIOExtensionProvider`, `CMIOExtensionDeviceSource`, `CMIOExtensionStreamSource`)，以独立系统扩展服务运行；
* **CoreMediaIO 硬件级直通 (零配置免提权)**：
  ACast 支持自动枚举系统中的 CMIO Sink 虚拟相机（如系统中已就绪的 OBS Virtual Camera 等），通过 `CMIOStreamCopyBufferQueue` 和 `CMSimpleQueueEnqueue` 直接将手机摄像头硬件解码帧注入虚拟相机队列，用户在 Zoom、FaceTime、Photo Booth 中无需安装新扩展或关闭 SIP，选择对应虚拟相机即可即开即用！
* **全面兼容 FaceTime、Zoom 与主流会议软件**：
  彻底突破了 macOS Sonoma / Ventura / Sequoia 对旧版 DAL 插件（`/Library/CoreMediaIO/Plug-Ins/DAL`）的签名与沙盒硬性屏蔽，无需关闭 SIP 或修改系统安全策略，FaceTime、Zoom、Photo Booth、Safari、Chrome 等应用可直接在摄像头列表中选用虚拟相机；
* **高画质与智能帧率自适应**：
  提供 1080P (1920x1080) 与 720P (1280x720) 30 FPS 两种标准视频流，支持色彩空间 `kCVPixelFormatType_32BGRA`，画面真实自然；
* **优雅待机占位图机制 (Standby Display Card)**：
  在手机未开始推流或连接建立中时，虚拟摄像头自动显示科技感十足的动态待机画面（包含清晰指引与毫秒级时钟），第三方会议软件绝不会因未连接而黑屏报错。

### 2. Android 手机端高清硬件编码与全功能摄像头推流
* **Camera2 硬件级采集 + MediaCodec AVC 硬件编码**：
  手机端基于 Android Camera2 API 采集，直接接入 `MediaCodec` Surface 输入端，全硬件管道零 CPU 内存拷贝，4.5 Mbps 高码率超低延迟 (<20ms) 传输；
* **一键切换摄像头与补光灯控制**：
  - 支持一键翻转前置/后置摄像头；
  - 支持后置摄像头补光灯（Torch）开关，暗光环境视频会议依然明亮；
  - 支持 1080P / 720P 分辨率热切换；
  - 手机端带实时取景预览窗口，方便随时调整构图角度。

### 3. Mac 控制端相机扩展中心与双轨分发
* **一键检测系统相机扩展与系统设置直达**：
  ACast Mac 端控制台内嵌【检测相机扩展状态】与【打开“相机扩展”设置...】按钮，路径直指 macOS【系统设置 > 通用 > 登录项与扩展 > 相机扩展】；
* **双轨分发架构 (Dual-Track Relay Pipeline)**：
  Mac 端硬解输出后同时支持 CoreMediaIO 硬件级直通和 TCP 本地环回链路分发，保证极致超低延迟与端到端无损画质。
