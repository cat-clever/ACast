# ACast v0.3.0 发版说明

## 更新亮点

### 1. 彻底修复 Android 端 HLS 直播服务与录屏初始化
* **参数传递不一致 Bug 彻底修复**：
  * 排查发现 `MainActivity` 中传递的是 `"code"`，而 `ScreenCaptureService` 中读取的是 `"resultCode"`，导致录屏授权参数始终为 0，底层 `MediaProjection` 与硬件编码器从未被激活；
  * 本次升级统一双向兼容传参，确保无论系统何时拉起前台录屏服务均能 100% 成功初始化硬件编码器；
* **推流服务提前预就绪**：
  * 将 `LocalHttpTsServer`（端口 8088）与 `FastMirrorSender`（端口 19999）的启动时机前置至 `MainActivity.onCreate()`，即使在点击录屏前，大屏电视与电脑探测端口也不会报错 Connection Refused；
  * 重构套接字绑定逻辑为 `setReuseAddress(true)` + `bind()`，彻底根除端口处于 TIME_WAIT 时引发的 `BindException`；
* **界面直观状态展示**：
  * 在手机端状态栏明确输出当前 HLS 直播流地址（如 `http://192.168.2.3:8088/live.m3u8`），电视拉流与电脑调试一目了然。

### 2. 控制端重磅升级：实时投屏视窗 + 鼠标操控滑动 + 键盘直接输入
* **双分栏专业控制视窗**：
  * 控制台窗口全面升级为宽屏专业布局，左侧提供 420x690 超大高保真手机画面专用视窗，右侧整合设备管理、快捷控制与运行日志；
* **macOS VideoToolbox 原生极速硬解**：
  * 采用 macOS 系统级硬件加速解码会话（`VTDecompressionSession`），自动解析 Annex-B NALU 并转换为 AVCC 格式，GPU 零拷贝极速出图，渲染延迟低于 20ms；
  * 自动保宽高比（Aspect Fit）居中自适应缩放渲染，未连接推流时呈现现代化交互指引；
* **鼠标点击与顺滑拖拽模拟触控**：
  * 鼠标在投屏画面中的点击（MouseDown）、拖拽移动（MouseDragged）、抬起（MouseUp）均自动精准换算为画面内相对坐标，归一化（0~10000）通过 FastMirror 通道毫秒级发往手机；
  * 手机端无障碍服务全面升级，支持区分单点轻触与连续平滑拖拽滑动，操作体验流畅丝滑；
  * 鼠标右键点击直接映射为手机【返回 (Back)】键，极其符合桌面操作直觉；
* **电脑键盘打字输入与物理按键支持**：
  * 点击投屏视窗直接获得键盘焦点；
  * 键盘按下 ESC 触发手机返回，Return 触发回车，Delete / Backspace 触发删除退格，方向键精准映射；
  * 电脑键盘直接打字（支持英文字符、数字、符号等），通过新增协议包 `MSG_TEXT_INPUT` (0x22) 直接将文本填入手机当前活动输入框！
