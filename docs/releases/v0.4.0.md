# ACast v0.4.0 发版说明

ACast v0.4.0 专项彻底解决了**手机锁屏后再次解锁、投屏屏幕一直是黑的但能控制手机**的严重系统生命周期缺陷。

---

## 核心技术与体验优化亮点

### 彻底解决锁屏后解锁屏幕一直是黑的但能控制手机的问题 (Unlock Screen Blackout Fix)
* **VirtualDisplay 亮屏/解锁自动唤醒重绑 (Surface Auto-Recovery)**：
  在 Android 端 `ScreenCaptureService` 中动态注册全局 `ACTION_SCREEN_ON`、`ACTION_SCREEN_OFF` 和 `ACTION_USER_PRESENT` 广播接收器；当检测到手机亮屏或用户解锁时，自动唤醒 VirtualDisplay 重新建立 Surface 镜像绑定，并接入 `VirtualDisplay.Callback` 监听系统的挂起与恢复，彻底解决 Android 系统息屏导致虚拟镜像挂起黑屏的底层缺陷。
* **反控操作智能唤醒屏幕与镜像 (Wake-on-Control)**：
  当用户在电脑端独立窗口点击鼠标或按键时，无障碍服务点亮屏幕的同时立即触发 `ScreenCaptureService.onScreenUnlocked()`，实现电脑端点按手机自动点亮屏幕并恢复彩色推流。
* **电脑端硬解会话失效自愈 (Decoder Invalidation Recovery)**：
  修复 macOS `ScreenMirrorView` 在会话失效（`decompressionSession == NULL`）且 SPS/PPS 内容未变时无法重新初始化的严重缺陷。只要会话为空或格式丢失，收到下一关键帧即刻 100% 重建 VideoToolbox 硬件解码器，杜绝画面永久黑屏。
* **解锁即时刷新全量 I 帧**：
  解锁瞬间向 MediaCodec 注入 `PARAMETER_KEY_REQUEST_SYNC_FRAME`，手机立即推送包含 SPS/PPS 的全新彩色 IDR 帧，绝不复用锁屏期间的全黑帧。
