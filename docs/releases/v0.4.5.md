# ACast v0.4.5 发版说明

发布日期：2026-11-06

ACast v0.4.5 为手机端（Android）带来了全面的 **Material 3 (Material You) 现代设计重构**！彻底告别过去杂乱的垂直按钮堆叠，采用卡片化布局、嵌套视口滚动、动态状态指示器以及高颜值设备直连卡片，带来更加专业现代的投屏体验。

---

## 🌟 核心更新亮点

### 1. 全新 Material 3 现代化卡片式手机界面
- **卡片化视觉架构**：告别以往无层次的按钮堆叠，划分为“核心投屏控制台”、“系统运行守护保障”、“目标设备列表”三大高质感圆角卡片；
- **自适应视口平滑滚动**：引入 `CoordinatorLayout` 与 `NestedScrollView`，无论在任何尺寸手机、折叠屏还是分屏模式下均能自适应完美展示，彻底解决小屏按钮溢出被截断的痛点；
- **品牌顶部栏与动态版本徽标**：清新 ACast 品牌标识、一键更新检测入口与随版本动态联动的 Pill 状态胶囊。

### 2. 交互式动态状态与大圆角触控按键
- **54dp 满宽立体主控投屏按键**：未连接呈现科技蓝（🚀 开启屏幕投屏），投屏中动态切换为珊瑚红（⏹️ 停止投屏），状态一目了然；
- **摄像头控制条折叠化设计**：启用摄像头后平滑展开微缩预览与翻转/补光/1080P 工具组，收放自如；
- **状态面板多维信息感知**：动态呈现本机推流 IP、实时音画 HTTP 直播流地址与对等直连状态。

### 3. 高颜值自定义设备发现列表
- **卡片式设备行（`item_device`）**：
  - 自动识别电脑控制端（💻 蓝色徽标、高亮直连 Chip、音画/反控就绪标识）；
  - 自动识别大屏电视（📺 琥珀黄徽标、DLNA 投屏 Chip）；
- **动态高度自适应计算**：嵌套在卡片内的列表随局域网发现设备数量实时撑开，杜绝滑动冲突与单行截断。

### 4. 守护服务入口全状态反馈
- 电脑鼠标反控与后台防杀白名单按键根据系统授权状态实时显示绿色就绪或琥珀黄未开启警示边框，指引清晰明了。
