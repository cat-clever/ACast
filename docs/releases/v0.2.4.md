# ACast v0.2.4 发版说明

## 更新亮点

### 彻底修复 macOS 及 Windows 端一键原地热更新失败的根因
* **规范用户级持久化缓存路径 (`GetUpdateCacheDir`)**：
  * **根因定位**：当用户通过 Finder、Dock 或 LaunchServices 从 `/Applications/ACast.app` 启动时，macOS 进程的默认工作目录 (CWD) 为根目录 `/`。旧版本使用相对路径 `update_cache`，在根目录下 `mkdir` 抛出 `EACCES (Permission denied)` 错误，导致 curl 下载立即返回错误码 23，提示“下载失败，网络异常或资源不存在 / 请检查网络或写入权限”；
  * **规范化迁移**：macOS 采用标准用户缓存目录 `~/Library/Caches/com.catclever.acast/update`，Windows 采用 `%LOCALAPPDATA%\ACast\update`，实现多级递归目录自动创建 (`CreateDirectoriesRecursively`)，彻底解除对当前工作目录的权限依赖。
* **三重网络加速与镜像容灾重试通道 (`DownloadFile`)**：
  * **第一重直连**：配置 15 秒连接超时与自动重试策略，直连 GitHub Releases 资产服务器；
  * **第二重与第三重高速镜像**：当直连遭遇国内网络环境波动、DNS 污染或超时，系统将自动无缝切换至高速加速镜像源 (`mirror.ghproxy.com` 及 `ghproxy.net`) 进行智能重试；
  * **安装包完整性校验**：严格校验下载资产文件大小与格式，杜绝下载到异常 HTML 错误页。
* **macOS 无感覆盖与进程守护平滑重启 (`ApplyMacOsUpdate`)**：
  * 后台脚本独立监控当前应用进程 PID，待原进程退出后执行平滑覆盖；
  * 自动卸载 DMG 临时挂载点并清理 quarantine 隔离属性，无缝唤起新版本应用。
