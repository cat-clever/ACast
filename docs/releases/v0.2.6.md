# ACast v0.2.6 发版说明

## 更新亮点

### 桌面控制端全面内置 Google 官方 ADB 调试桥工具
* **开箱即用，零环境依赖**：
  * **解决痛点**：彻底解决普通用户或新电脑打开控制端时提示“`[USB] 本地未检测到 adb 命令行工具`”的问题；
  * **出厂直接内置**：
    * **macOS 平台**：DMG 发行包中直接内置 Google 官方 macOS 原生 Mach-O `adb` 工具（置于 `ACast.app/Contents/MacOS/adb` 并自动预置可执行权限）；
    * **Windows 平台**：ZIP 发行包中直接内置 Google 官方纯净版 `adb.exe`、`AdbWinApi.dll` 与 `AdbWinUsbApi.dll`（与 `acast_desktop.exe` 同目录）；
* **智能四级自动探测与动态补齐机制 (`AdbTunnel::GetAdbPath`)**：
  * **第一级**：100% 优先匹配当前可执行文件同级目录下的内置 ADB 工具；
  * **第二级**：匹配用户级应用持久化工具缓存目录（`~/Library/Caches/.../tools` 或 `%LOCALAPPDATA%\ACast\tools`）；
  * **第三级**：自动扫描环境变量中的 Android SDK 路径（`ANDROID_HOME` / `ANDROID_SDK_ROOT`）与标准 SDK 安装路径；
  * **第四级（兜底自愈）**：若全系统均未检测到 ADB，系统将自动从 Google 官方高速下载通道静默安装至用户工具目录，无需用户手动配置任何环境变量或 Android Studio。
