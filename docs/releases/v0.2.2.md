# ACast v0.2.2 发版说明

## 更新亮点

### 1. 控制端全面支持 FastMirror 私有协议局域网 Wi-Fi IP 与端口直连
* **突破网络拓扑限制**：桌面控制端（Windows 原生 GUI & macOS Cocoa GUI）不再局限于 USB 数据线连接，现已全面支持局域网 IP 与端口直连！
* **交互面板升级**：在“手机反控中心”卡片中新增局域网手机 IP 输入框（默认自动记忆如 `192.168.2.3`）与端口输入框（默认 `19999`），支持一键【连接 Wi-Fi 直连】与【断开直连】，并实时呈现毫秒级连接状态；
* **双通道智能无缝流转**：
  * 当局域网 Wi-Fi 私有协议通道已建立时，快捷反控操作（【返回】、【桌面】、【多任务】）优先通过自研 FastMirror 私有二进制协议直接发送至手机端无障碍服务，实现 < 20ms 的超低延迟反控；
  * 当局域网未连接但插入了 USB 数据线时，自动无感回退至 ADB 底层反控通道；
  * 双通道无缝容灾，满足无线自由投屏与有线极速控制的全场景需求。

### 2. 手机端与私有协议网络层健壮性深度强化
* **网络分包保护与完整帧接收**：优化 Android 端 `FastMirrorSender` 的控制信道流解析，引入 `readFully` 机制，彻底杜绝 Wi-Fi 网络抖动拆包黏包导致的连接意外中断；
* **手机端直观呈现本端 IP**：Android 手机开启投屏后，界面自动提取并显示本机局域网 IP 与端口（例如 `本机IP: 192.168.2.3:19999`），指引用户在桌面控制端输入直连。
