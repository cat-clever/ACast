# ACast v0.4.4 发版说明

发布日期：2026-11-06

ACast v0.4.4 带来了全新纯图标悬浮胶囊控制栏、彻底解决 Android 14+ 状态栏下拉菜单栏无法共享推流问题、增强顶部下拉手势与快捷键支持，以及摄像头局域网直播流打通！

---

## 🌟 核心更新亮点

### 1. 控制端虚拟按键全新重构为纯图标悬浮胶囊栏
- **纯图标极简设计**：彻底移除了多余文字标签，仅保留纯粹经典的导航三键：`◀`（返回）、`○`（桌面）、`▢`（任务）；
- **深色毛玻璃 HUD 胶囊条**：内置微光边框、平滑阴影与微触控按压反馈，支持悬停 Tooltip 提示；
- **智能感应悬浮展现**：默认完全透明隐藏，鼠标移至视窗底部约 80px 区域时平滑渐变浮现，移开或静止 3 秒自动平滑隐去；
- **触控防误触与零遮挡**：在胶囊按键上点击直接触发对应动作，拖拽手机画面时胶囊瞬间隐去，彻底不挡视窗手势；
- **全视窗纯净呈现**：移除常驻底栏，主窗口投屏高度从 615 扩充至 657 像素，独立弹窗实现 100% 满屏纯净投屏。

### 2. 彻底解决 Android 14+ 状态栏下拉菜单栏无法共享推流问题
- 适配 Android 14+（API 34+）`MediaProjectionConfig.createConfigForDefaultDisplay()`；
- 底层强制锁定捕获整个默认屏幕，彻底屏蔽导致系统状态栏/通知栏被安全层隔离的“单个应用”模式；
- 手机顶部状态栏、下拉通知栏、快捷设置控制中心 100% 完整推流呈现在电脑控制端。

### 3. 顶端下拉手势穿透与菜单栏控制增强
- 智能识别从手机顶部边缘（`downY <= 90px`）向下拉动的鼠标手势，轻拉直接唤起系统原生通知栏（`GLOBAL_ACTION_NOTIFICATIONS`），深拉唤起快捷设置控制中心（`GLOBAL_ACTION_QUICK_SETTINGS`）；
- 电脑端新增键盘快捷键：
  - `F1`：瞬间下拉/展开通知栏
  - `F2`：瞬间展开快捷控制中心
  - `ESC` 或鼠标右键：瞬间返回/收起。

### 4. 摄像头流局域网直播直通与 OBS 快速桥接
- Android 端摄像头模式同步分发至本地 HTTP TS 直播流服务（`http://<手机IP>:8088/live`）；
- 支持 OBS 媒体源拉流与窗口采集无缝转推虚拟摄像机，秒出画面告别黑屏。
