# ACast v0.1.1 发布说明

## 更新内容

### 1. 统一各端高分辨率软件图标
* **全平台视觉统一**：现代深蓝渐变底色 + 悬浮大屏电视外框 + 无线投屏声波 + 移动手机端 Cast 图标。
* **macOS**：原生多尺寸矢量级 `acast.icns`，绑定 App Bundle 图标。
* **Windows**：原生多分辨率 `acast.ico`，通过 `app.rc` 资源编译嵌入可执行文件 PE 头，`.exe` 直接自带图标。
* **Android**：生成全套 `mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}` 启动图标。
* **iOS**：包含标准 1024x1024 高清 `AppIcon.png`。

### 2. 优化 macOS DMG 安装体验
* **剔除 README**：DMG 镜像内部不再放置冗余的 `README.md`。
* **一键拖拽安装快捷方式**：DMG 镜像根目录内置指向系统 `/Applications` 的快捷替身，挂载后直接拖拽 `ACast.app` 即可完成安装。
* **完善 App Bundle 属性**：写入规范的 `Info.plist`，声明 `CFBundleIconFile` 为 `acast.icns`。
