# ACast v0.2.7 发版说明

## 更新亮点

### Android 发射端全面升级为 HLS 实时流协议架构
* **彻底根治大屏接收端拉流失败 (Operation Stopped)**：
  * **背景与根因**：Apple 平台的原生媒体框架 `AVPlayer`（包括 macOS 接收端 ADisplay、Apple TV 等）在拉流时强制要求符合 RFC 8216 规范的 HLS（HTTP Live Streaming）播放列表；对于裸 HTTP MPEG-TS 长连接流（`live.ts`），AVPlayer 内部探测超时会抛出 `AVErrorOperationStopped`；
  * **全新内存实时切片引擎 (`LocalHttpTsServer`)**：
    * 动态生成符合规范的 Live 直播清单 `http://<ip>:8088/live.m3u8`；
    * 采用毫秒级滑动窗口切片器，每个分片（`segment-<seq>.ts`）约 1 秒，首包均携带完整的 PAT、PMT、SPS/PPS 与 IDR 关键帧；
    * 严谨去除点播结束符 `#EXT-X-ENDLIST`，确保实时持续拉流；
    * 首屏快速响应：若客户端连入瞬间切片未就绪，系统强制触发关键帧生成并在 1 秒内完成首片输出，实现大屏秒开；
  * **协议智能向下兼容**：
    * 完整保留原有 `/live.ts` 长连接推流通道，保证老旧智能电视或第三方 DLNA 播放设备无缝兼容；
    * DLNA DIDL-Lite 元数据根据推送流类型自动适配 `application/vnd.apple.mpegurl` 与 `video/mp2t`，无缝协同 ADisplay 等接收端。
