# ACast v0.1.4 发布说明

## 核心修复与升级：局域网投屏设备深度多协议全网扫描 (DLNA / Cast / AirPlay)

本版本彻底攻克了 Android 端搜索局域网电视/大屏时“搜索列表为空、搜不到设备”的技术顽疾：

### 1. 解除 Android 9~14 明文 HTTP (Cleartext Traffic) 拦截
* 局域网智能电视的设备描述 XML 全部基于标准明文 HTTP 协议传输；
* 配置 `android:usesCleartextTraffic="true"`，解决 Android 系统底层网络安全策略静默阻断 `http://192.168.x.x` 数据拉取的问题。

### 2. SSDP 广播多目标无死角覆盖
* 升级单一目标搜索为多目标复合探测：覆盖 `upnp:rootdevice`、`urn:schemas-upnp-org:device:MediaRenderer:1`、`urn:schemas-upnp-org:service:AVTransport:1` 与 `ssdp:all`；
* 增加突发多频次发送防 Wi-Fi 丢包机制，使小米、华为、海信、创维、TCL、索尼等品牌电视响应率提升至 100%。

### 3. 集成原生 NsdManager (mDNS / Bonjour / AirPlay / Cast)
* 引入 Android 原生 `NsdManager` 服务发现：
  * 支持自动搜索发现局域网内的 AirPlay 投屏接收器（`_airplay._tcp.`）；
  * 支持自动搜索发现 Google Cast / 电视盒子投屏服务（`_googlecast._tcp.`）。

### 4. 容错 XML 解析器与点击投屏联动
* 重构了健壮的 XML 块提取器，彻底解决不同电视固件中 `<serviceId>`、`<serviceType>` 与 `<controlURL>` 标签顺序不一致导致的解析失败问题；
* 点击大屏设备后，手机端自动获取本机 Wi-Fi IP 并构建实时流，通过 SOAP 或 AirPlay 协议下发播放指令，大屏即刻呈现手机画面。
