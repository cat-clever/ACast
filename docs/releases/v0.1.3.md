# ACast v0.1.3 发布说明

## 核心修复与优化 (Critical Fixes)

### 1. 彻底修复 Android 手机点击“开启屏幕投屏”闪退自动退出的问题
* **适配 Android 14 (API 34) 严格规范**：在 `startForeground()` 中显式指定 `FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION`，彻底消除前台服务启动崩溃；
* **注册 MediaProjection 回调**：在创建虚拟显示（`createVirtualDisplay`）之前注入 `MediaProjection.Callback`，满足 Android 14+ 底层强制要求；
* **硬件编码器动态容错与降级**：
  * 对屏幕原始分辨率进行 16 字节对齐与自适应缩放（防止 2K / 超长比例屏幕超出芯片硬编码宏块限制导致 Codec 崩溃）；
  * 首选配置失败时自动无缝降级为标准 720P 安全参数重试，保证任何机型稳定出流；
* **运行时权限与静音容错**：在开启投屏前动态申请 `RECORD_AUDIO` 与 `POST_NOTIFICATIONS` 权限；即使麦克风权限被拒绝，也自动转入纯画质投屏，绝不闪退；
* **全局异常崩溃守护**：注册主线程与全局未捕获异常拦截器，彻底杜绝无提示静默闪退。

### 2. 界面与协议文案规范化
* 全面剔除所有“B站协议”字样，统一规范显示为行业通用协议名称：**DLNA / Cast / AirPlay**。
