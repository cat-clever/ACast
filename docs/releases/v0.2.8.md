# ACast v0.2.8 发版说明

## 更新亮点

### 局域网全自动双向对等发现 (Peer Discovery) 与去端口化
* **彻底移除端口展示，体验至简**：
  * 手机端界面与通知栏彻底隐藏内部通信端口（`19999`），控制端界面彻底移除 IP 与端口文本框，用户无需手动抄录、记忆或输入任何技术参数；
* **电脑与手机自动互相发现对方 (全双工 UDP 广播协议)**：
  * **电脑控制端**：
    * 启动时后台自动广播宣告与监听（UDP 19998）；
    * 自动列出局域网内所有在线手机（如 `📱 小米 14 (192.168.2.3)`）以及 USB 连入的设备；
    * 下拉菜单直接选择手机，一键点击【连接手机】瞬间建立直连反控；
  * **手机发射端**：
    * 自动扫描并实时呈现局域网内的电脑控制端（如 `💻 MacBook Pro (192.168.2.5)`）；
    * 手机设备列表同时汇聚电脑控制端与电视大屏设备；
    * 手机端直接点击电脑控制端，系统向电脑发送一键直连请求，电脑端自动接入手机建立反控通道；
    * 手机端点击大屏设备，自动发起 HLS 实时流投屏。
