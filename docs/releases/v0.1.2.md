# ACast v0.1.2 发布说明

## 核心新特性：全平台内置直接在线热更新 (In-App Auto-Update)

本版本引入了全新的直接在线热更新体系，彻底免除手动下载、手动解压或手动挂载 DMG 的繁琐步骤：

### 1. macOS 端直接热更新
* **免手动打开 DMG**：客户端后台静默下载最新 `acast-macos-universal.dmg` 后，自动完成后台静默挂载；
* **原地无感覆盖**：自动检测当前正在运行的应用程序位置（如 `/Applications/ACast.app`），通过平滑辅助进程完成原子替换并重启新版本，当前进程平稳退出；
* **全流程闭环**：卸载挂载卷并清理临时缓存，用户无需手动打开 DMG 拖拽安装。

### 2. Windows 端直接热更新 (x86_64 与 ARM64 双架构)
* **免手动解压 ZIP**：后台静默拉取适配当前架构的 ZIP 包并解压；
* **突破可执行文件锁定**：通过轻量级异步批处理守护进程，在旧进程退出后瞬间替换 `.exe` 并重新拉起新版，无需用户手动覆盖或重启电脑。

### 3. Android 手机端直接更新
* **应用内一键升级**：集成 `AutoUpdater` 模块与 Android 7.0+ 官方 `FileProvider` 机制；
* **直接调起安装器**：后台高速下载 `acast-android.apk` 后，直接发起系统覆盖安装意图，一键完成升级。
