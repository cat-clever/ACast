# ACast v0.3.6 发版说明

ACast v0.3.6 专项根治了“控制手机导致控制台端卡住、假死与转彩球”的核心痛点，完成了控制端异步反控架构的彻底重构，强化了 FastMirror 局域网私有高速反控协议的长连接保活与滑动窗口对齐，并在手机端增加了无障碍反控未就绪时的直观引导提示。

---

## 核心修复与技术升级亮点

### 1. 彻底根治控制手机时控制台端卡顿（UI 主线程 0 阻塞）
* **痛点根因分析**：
  在之前的版本中，当 FastMirror 协议未就绪或因超时断开时，系统会自动 fallback 回退到 ADB 反向控制通道。然而，由于部分用户的 Android 手机是通过局域网无线 Wi-Fi 调试连接（例如 `192.168.2.8:5555`），单次外部进程调度与网络传输耗时高达 500ms ~ 2000ms。原代码在 UI 主线程（Cocoa Event Loop / Win32 WndProc）中同步调用外部进程，用户连续点击按键或拖动鼠标，直接导致主线程被连续挂起数十秒，操作系统判定应用无响应（macOS 出现旋转彩球 Beachball，Windows 出现“未响应”并灰屏）。
* **底层异步工作队列（`AdbWorkerQueue`）**：
  在 `core/src/adb_tunnel.cpp` 中内置安全的单线程异步任务调度器。所有控制注入（`InjectTap`、`InjectSwipe`、`InjectText`、`InjectKeyEvent`、`InjectBack`、`InjectHome`、`InjectAppSwitch`）均改为向异步工作队列投递任务，UI 主线程调用耗时直接降至 **0ms（< 0.001 毫秒）** 立即返回！
* **背压防积压丢弃机制（Backpressure Rate Limiting）**：
  针对高频鼠标拖拽/移动手势，工作队列在排队超过上限时自动丢弃过时的中间触控点，只保留最新手势点，彻底避免手势堆叠累积延迟；系统功能按键（返回、主页、多任务、文本输入）永不丢弃，确保 100% 顺序精确执行。

### 2. FastMirror 私有协议长连接链路稳定性与保活升级
* **移除误判读取超时断开**：
  移除了长连接控制 socket 上强制 3 秒读取超时的限制，替换为系统标准的 `SO_KEEPALIVE` 长连接保活。即便手机在闲置或等待推流时未下发音视频包，反控通信通道也不会被误杀断开，杜绝误回退到慢速 ADB。
* **主动心跳探测（Heartbeat PING/PONG）**：
  C++ 客户端启动专职后台心跳线程，每隔 4 秒向手机端发送 `PING (0x03)` 包，Android 发射端自动应答 `PONG (0x04)` 包，保证 TCP 链路在局域网复杂路由器环境下不会被 NAT 超时回收。
* **全量循环发送与非阻塞重试**：
  将 `SendRawPacket` 单次 `send` 重构为 `while (total_sent < total)` 完整发送循环，对网络轻微背压（EAGAIN/EWOULDBLOCK）优雅重试，杜绝部分发送时的非预期断网。
* **滑动窗口自愈重对齐（Sliding Window Resync）**：
  双端均增加单字节滑动匹配探测机制。若网络传输中出现瞬时脏字节或单字节错位，两端自动向左滑动 1 字节并继续探测，直到再次精确对齐魔数（`0x4D46` / `0x464D`），彻底杜绝帧边界丢失导致的永久解包失效。

### 3. 手机端无障碍服务智能引导 Toast 提示
* 当用户在电脑控制屏幕上点击“返回”、“桌面”、“任务”等按键，若手机端尚未开启【ACast 投屏反控】无障碍服务，手机屏幕将立即弹出醒目的悬浮引导 Toast：
  > “💡 ACast 提示：请在手机【系统设置 - 无障碍】中开启【ACast 投屏反控】，以允许电脑控制手机”
* 帮助用户一目了然定位问题，杜绝“按键没有反应”的误解。
