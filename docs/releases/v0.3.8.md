# ACast v0.3.8 发版说明

ACast v0.3.8 专项彻底解决了三大核心体验与稳定性问题：
1. **弹出独立控制屏幕窗口在投屏 1 分钟左右画面卡死/假死**的问题；
2. **电脑向手机打字输入时输入框只保留最后一个按键字母**的问题，并新增退格删除（Backspace/Delete）支持；
3. **高刷鼠标拖拽连续滑动导致 UI 线程阻塞与 Socket 背压假死**的问题。

---

## 核心技术与体验优化亮点

### 1. 彻底解决弹出独立控制屏幕窗口卡死与断流 Bug
* **单一统一视图无缝迁移架构 (Single ScreenView Reparenting)**：
  废弃了在主窗口与独立窗口各创建一套 `ScreenMirrorView` 的割裂设计。重构为单一全局 `screenView` 实例，在弹出独立窗口与收回主窗口时，直接在 Cocoa 视图层级中无感平移挂载（`reparenting`）。
  - **硬件解码器零中断**：`VTDecompressionSession` 与 SPS/PPS 配置上下文全生命周期保留，跨窗口切换无需重建解码器，杜绝丢帧、黑屏与切换卡死；
  - **彻底废除子线程跨线程调用 AppKit UI 状态**：视频数据回调直接喂给单一视图，绝不在每秒 60 次的后台子线程中读取 `[window isVisible]`，从根本上杜绝跨线程死锁与误判断流。
* **零积压最新帧调度器 (Zero-Lag Latest Frame Coalescing)**：
  重构 macOS VideoToolbox 帧渲染管道，主线程渲染消费与解码回调完全解耦。当系统负载或帧率波动导致主线程繁忙时，自动保留最新一帧并立即释放未及渲染的旧帧，从源头杜绝每秒 60 帧产生数十 GB 的 `VTCreateCGImageFromCVPixelBuffer` 内存积压，彻底消除 macOS `com.apple.coremedia.videodecoder` 进程被 watchdog 判定内存泄露引发的 `XPC_ERROR_CONNECTION_INTERRUPTED` 强杀崩溃。
* **高刷鼠标触控背压限流 (Touch Rate Limiting)**：
  对高频连续拖拽 `mouseDragged` 进行 16ms（60Hz）背压限流，防止外接电竞高刷鼠标以千赫兹频率向 UI 主线程疯狂发起阻塞式 Socket `send()`；`mouseDown` 和 `mouseUp` 保证 100% 立即发送。
* **网络发送失败杜绝主线程同步 join 死锁**：
  在 `SendRawPacket` 中移除了在 UI 线程同步调用 `Disconnect()`（调用 `join` 等待子线程）的死锁代码，改为异步安全退出，杜绝 macOS 彩球假死。
* **Android 手机端屏幕常亮锁强化 (Screen Bright WakeLock)**：
  `ScreenCaptureService` 新增 `PowerManager.SCREEN_BRIGHT_WAKE_LOCK | ACQUIRE_CAUSES_WAKEUP`，保证投屏期间手机屏幕 100% 不熄屏休眠，杜绝系统 1 分钟息屏超时导致 VirtualDisplay 停止推流；且新客户端连接时立即触发 `requestKeyFrame()` 生成首帧 IDR 关键帧。

### 2. 彻底解决电脑键盘输入只有最后一个字母的 Bug
* **光标位置剪贴板优先粘贴 (Clipboard Paste Injection)**：
  重构 `ControlAccessibilityService.injectText`，优先通过系统剪贴板光标处粘贴（`ACTION_PASTE`），支持中英文长句、单词在光标处自然连续打字。
* **已有文本拼接追加兜底**：
  在不支持粘贴的特殊输入控件中，读取已有文本并在末尾追加拼接后更新，彻底废除直接用单个字母覆盖整框文本（`ACTION_SET_TEXT`）的旧缺陷。
* **全能退格删除键 (Backspace/Delete) 支持**：
  `injectKey` 新增对按键码 7（`KEY_DEL`）的支持，支持逐字退格删除打错字符。
