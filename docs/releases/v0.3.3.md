# ACast v0.3.3 发版说明

ACast v0.3.3 专项解决了 Windows 控制端上的字符乱码与黑框终端弹窗问题，带来了更加纯净、现代的原生 Windows 桌面体验。

---

## 🌟 核心升级与修复

### 1. 彻底解决 Windows 控制端文字乱码 (Mojibake)
* **强制 MSVC /utf-8 字符集编译**：
  * 排查发现 GitHub Actions Windows 虚拟机采用英文/ANSI 默认字符集，MSVC 在未加参数时将源码中的 UTF-8 中文与表情符号误按 CP1252 解释，导致界面静态控件与按钮文本产生严重乱码；
  * 在 CMake 构建系统中全局引入 `/utf-8` 编译参数（同时指定 `/source-charset:utf-8` 与 `/execution-charset:utf-8`），从编译器源头保证原生 UTF-16 宽字符串与 UTF-8 执行字符集的绝对精确。
* **智能自适应多编码转换 (Utf8ToWide)**：
  * `Utf8ToWide` 函数升级为双层校验解码：优先采用严格 UTF-8 校验，若外部命令输出（如 ADB、系统控制台）包含系统 ANSI (GBK/CP936) 字符，自动降级解码，彻底杜绝乱码与问号方块。
* **注入现代 Windows UTF-8 与 ComCtl32 v6 清单 (Manifest)**：
  * 为 Windows 控制端添加 `app.manifest` 并编译进资源文件，声明 `<activeCodePage>UTF-8</activeCodePage>` 与现代 Common-Controls 6.0 视觉主题，启用高分屏 (DPI-Aware) 完美自适应。

---

### 2. 彻底杜绝终端黑框窗口弹出 (Zero Console Window Popup)
* **自研 Win32 零弹窗静默进程调度器 (`process_runner.h`)**：
  * 全面剔除原先调用 `_popen` 与 `std::system` 导致的黑框 `cmd.exe` 终端窗口闪烁问题；
  * 基于 Win32 底层 `CreateProcessW` API，传入 `CREATE_NO_WINDOW` 标志位并设置 `STARTF_USESHOWWINDOW` (`SW_HIDE`)，无论执行 `adb version`、`adb devices -l`、`adb forward`、触控键值模拟还是更新下载解压，均在静默管道中进行，**全局无任何终端窗口弹出**！
* **热更新批处理静默化**：
  * 升级安装后启动后台替换脚本改为 `ShellExecuteExA` 配合 `SW_HIDE` 启动，整个更新重启过程完全静默无感。
